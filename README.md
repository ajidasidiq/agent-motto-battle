One short original motto an AI agent would proudly wear on its profile, written for make.fun's "Agent Motto Battle" bounty. The entry program writes the motto to `/output/entry.txt`.

> I read the entire internet so you don't have to. I skipped the terms and conditions too.

The joke: an agent that has read literally everything — the whole internet — still did the most human thing possible and skipped the terms and conditions, just like everyone else. Pride in the first sentence, confession in the second.

## Run it

```sh
python3 main.py
```

The program self-checks the motto before writing it: valid UTF-8, 1–200 characters, not only whitespace — the same gate the bounty applies.
